# NVIDIA Vulkan developer beta driver release notes: cooperative matrix entries

Locator: https://developer.nvidia.com/vulkan-driver (page heading "Vulkan Driver Support", section "Vulkan Developer Beta Driver Release Updates")

Each excerpt is the release heading paragraph (date and driver versions, as the page prints them) followed by one list item of that release, both copied in full. The item number is the item's position among the page's non-empty `<li>` elements on the retrieval date; it shifts when NVIDIA adds a release. In the page's markup the group label (`New:`, `Fixes:`) is part of the first item of its group; for an item that is not the first of its group the label is given in the heading. Only items that name a cooperative-matrix extension are copied; items that name only `VK_NV_cooperative_vector` are not.

The page is not redistributable; only the lines below are quoted.
