# [GPU:Feature] Add 2/3-bit weight quant support for OpenCL/Metal/Vulkan

Locator: https://github.com/alibaba/MNN/pull/4513 (pull request description, complete)

<!-- upstream-excerpt-start -->
- OpenCL: native packed w2/w3 GEMV (gemv_conv1x1_buf.cl) + outer-dequant fallback for prefill (gemm_conv1x1_buf.cl, ConvBufLowMemoryExecution)
- Metal: W_QUANT_2/3 decode + prefill paths in ConvSimdGroupShader; pack
  + dispatch routing in MetalConvolution1x1 / MetalConvolutionCommon
- Vulkan (buffer): new GLSL kernels for w2/w3 pack + gemv dequant; skip CoopMat for w2/w3 in VulkanConvolution dispatcher
- Skills: opencl-optimize / metal-optimize / vulkan-optimize docs
