# bugfix: introduce vulkan command pipeline barrier for pipelines with more than 1 GEMM dispatch

Locator: https://github.com/jeffbolznv/vk_cooperative_matrix_perf/pull/11 (pull request description, complete)

<!-- upstream-excerpt-start -->
Without the barrier the vulkan command pipeline will overlap shader execution, which helps to hide latency, helps to achieve better occupancy etc., especially for smaller sizes, but it also makes a difference for the hardcoded 4096^3. By introducing the command pipeline barrier whenever multiple GEMM dispatches are issued in the same pipeline, we make sure there is no overlap and we actually measure per isolated GEMM execution perf.
<!-- upstream-excerpt-end -->
