# vulkan: 64-bit im2col

Locator: https://github.com/ggml-org/llama.cpp/pull/16135 (pull request description, complete)

<!-- upstream-excerpt-start -->
Add variants of the im2col shaders that use buffer_device_address/buffer_reference, and use 64-bit address calculations. This is needed for large convolutions used in stable-diffusion.cpp.

I've been working on getting https://github.com/leejet/stable-diffusion.cpp/pull/778 to work in Vulkan. The main thing that's missing is that it does 2d and 3d convolutions that have intermediate im2col buffers that are larger than 4GB. This change fixes the im2col part, I'll make a separate change for the matmul part.

Memory allocations larger than maxMemoryAllocationSize are not technically forbidden, and at least NVIDIA's windows driver will allocate more than 4GB.
<!-- upstream-excerpt-end -->
