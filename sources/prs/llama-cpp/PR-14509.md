# vulkan: support mixed/deepseekR1 FA head sizes

Locator: https://github.com/ggml-org/llama.cpp/pull/14509 (pull request description, first 1200 of 6995 characters)

<!-- upstream-excerpt-start -->
https://github.com/ikawrakow/ik_llama.cpp/discussions/562#discussioncomment-13636837 suggested to add support for deepseek FA head sizes. I tested with a quantized version of https://huggingface.co/deepseek-ai/DeepSeek-V2-Lite.

Performance is not great, but this is functional and I can tune it in later changes. The coopmat2 path has some spilling, the coopmat1 path falls back to scalar due to shared memory limits...
