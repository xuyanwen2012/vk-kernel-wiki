# vulkan: optimize decodeFuncB in coopmat2 mul_mat_id shader

Locator: https://github.com/ggml-org/llama.cpp/pull/18349 (pull request description, first 1197 of 7682 characters)

<!-- upstream-excerpt-start -->
Stacked on #18332.

Disable robustness, remove the OOB check in decodeFuncB, and initialize the row_ids to zero to avoid OOB access.

Don't slice/offset the B matrix to ic * BN, only to adjust the coord back down to the range [0, BN) in decodeFuncB. Instead just slice with a row offset of zero and remove the '& (BN - 1)'. This allows the compiler to common some of the shared memory loads.
