# vulkan: Implement mmvq for iq1_s/iq1_m

Locator: https://github.com/ggml-org/llama.cpp/pull/18450 (pull request description, first 1200 of 6986 characters)

<!-- upstream-excerpt-start -->
Add mmvq variants of iq1_s/iq1_m. This uses a version of the lookup table (same as cuda) that's more friendly to dp4.

I initially started looking into this after downloading a devstral 2 model in iq1 format (because it fits in 32GB). This change makes devstral2 more incoherent, but it's already incoherent without mmvq and even with the cuda backend, but the incoherence gets worse with mmvq. The llama3 IQ1 model stays coherent. I don't think this indicates a bug with this change, I think devstral2 just doesn't work with this format.
