# vulkan: only use M-sized matmul on Apple GPUs

Locator: https://github.com/ggml-org/llama.cpp/pull/5412 (pull request description, complete)

<!-- upstream-excerpt-start -->
While Metal is the preferred backend while targeting Apple GPUs, using the Vulkan backend is very useful when you're indirectly accessing the GPU from a different context, such as when running in a Virtual Machine.

Right now, Vulkan backend's L-sized and S-sized matmuls are broken on Apple GPUs, so let's force using M-size with this vendor.
