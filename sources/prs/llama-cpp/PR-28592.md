# vulkan: Convert FILL to distribute workgroups in 2D to avoid exceeding maxComputeWorkGroupCount

Locator: https://github.com/ggml-org/llama.cpp/pull/28592 (pull request description, first 1200 of 3859 characters)

<!-- upstream-excerpt-start -->
## Overview
Fixes #28247. `maxComputeWorkGroupCount` is 65535 on all axes for Intel GPUs (Windows and Linux) and Adreno GPUs, and when running Qwen 3.8 flash next we were seeing FILL exceeding this value when context gets long, resulting in an assert failure. This PR works around this by changing the work group distribution from 1D to 2D. Original patch comes from @danielstevens277-debug

- Xeon W9-3595X, 256GB RAM, Arc Pro B70 (driver: 32.0.101.8974), Win 11 24H2
