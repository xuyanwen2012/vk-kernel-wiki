# vulkan: Multi-pass softmax for large number of cols

Locator: https://github.com/ggml-org/llama.cpp/pull/17892 (pull request description, first 1200 of 11953 characters)

<!-- upstream-excerpt-start -->
When the number of cols is large, split each row across multiple workgroups. There are three phases that communicate partial results through temp buffers:
(1) compute max partials
(2) take max of partials, compute sum(exp(x-max)) partials
(3) sum partials, compute scaled result

https://github.com/ggml-org/llama.cpp/pull/17004/commits/a84dfd3e1072bcf422b90dc4b03d334395c90fe4 added a similar optimization for ggml-cuda, I guess this is needed to sample probabilities above a threshold.
