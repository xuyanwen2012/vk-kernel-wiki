# Vulkan: route large matmuls to medium tile on Adreno

Locator: https://github.com/ggml-org/llama.cpp/pull/24877 (pull request description, complete)

<!-- upstream-excerpt-start -->
## Overview

On Qualcomm Adreno GPUs (Vulkan backend), inference with q4_0 models breaks, once the prompt grows past ~200 tokens and the batch exceeds 32. Short prompts
work fine.


## Additional information

For non-coopmat devices, ggml_vk_guess_matmul_pipeline picks the tile by M/N:
M,N <= 32 -> small, <= 64 -> medium, otherwise -> large. With a long prompt the large q4_0 tile gets selected, and that shader fails on Adreno.

The per-type guard (ggml_vk_matmul_shmem_support) doesn't disable the large tile here because its computed footprint (~16.9 KB) is under the reported maxComputeSharedMemorySize, so the large tile stays enabled and is hit at runtime.

Before: crashes/hangs on long prompts with q4_0 on Adreno.
After: long-prompt inference completes; short prompts unchanged.
