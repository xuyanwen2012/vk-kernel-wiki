# vulkan: Use larger loads in scalar/coopmat1 matmul

Locator: https://github.com/ggml-org/llama.cpp/pull/15729 (pull request description, first 1182 of 5874 characters)

<!-- upstream-excerpt-start -->
I think glslang will translate an access like x[i][1].z to
```
OpAccessChain ... x, i, 1, 2
OpLoad float16_t ...
```

rather than loading all of x[i] in a single OpLoad. Change the code to explicitly load the vector/matrix.
