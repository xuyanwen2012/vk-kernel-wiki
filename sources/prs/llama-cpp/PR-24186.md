# vulkan: check coopmat2 features before reporting support

Locator: https://github.com/ggml-org/llama.cpp/pull/24186 (pull request description, complete)

<!-- upstream-excerpt-start -->
## Overview

Mesa ANV (and I think also RADV) have started supporting features of the NV_coopmat2 extension recently, which leads to erroneous device reporting like this:

> ggml_vulkan: 0 = Intel(R) Arc(tm) A770 Graphics (DG2) (Intel open-source Mesa driver) | uma: 0 | fp16: 1 | bf16: 1 | warp size: 32 | shared memory: 49152 | int dot: 1 | matrix cores: NV_coopmat2

To avoid this confusion, check for required features before reporting device support.
