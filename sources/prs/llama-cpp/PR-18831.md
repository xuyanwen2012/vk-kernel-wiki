This reverts commit 980b7cd17e055c8c587f79ffda7eb4fddf405566.

The actual root cause for https://github.com/ggml-org/llama.cpp/issues/17297 should've been fixed in https://github.com/ggml-org/llama.cpp/pull/17887, therefore we should be able to revert the change for full subgroups in #17356.

We are seeing 1.3x - 3.9x performance improvement in pp512 for older Intel GPU like ArrowLake and MeteorLake.
