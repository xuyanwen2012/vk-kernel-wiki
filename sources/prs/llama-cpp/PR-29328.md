# vulkan: tune KHR cooperative matrix support for Adreno GPUs

Locator: https://github.com/ggml-org/llama.cpp/pull/29328 (pull request description, complete)

<!-- upstream-excerpt-start -->
## Overview

This PR enables `VK_KHR_cooperative_matrix` (coopmat) support in the Vulkan backend for Qualcomm Adreno GPUs that have hardware matrix cores. The initial target is **Snapdragon 8 Elite Gen 6**.

Coopmat is only enabled when the device exposes both `VK_KHR_cooperative_matrix` and `VK_QCOM_cooperative_matrix_conversion`. Adreno devices without these extensions keep their current behaviour and do not use coopmat.

## Additional information

  - Adds a new `vk_device_architecture::QUALCOMM_ADRENO` value.
  - Qualcomm devices return coopmat support only when the architecture is `QUALCOMM_ADRENO`. Other Adreno GPUs are excluded.
  - Adds Adreno-specific medium warptiles (`m_warptile`, `m_warptile_mmq`) with 64-wide workgroups when coopmat is available.
