# vulkan: Support UPSCALE w/antialias

Locator: https://github.com/ggml-org/llama.cpp/pull/18327 (pull request description, complete)

<!-- upstream-excerpt-start -->
I saw this message in a llama-mtmd-cli repro:

```
warmup: *****************************************************************
warmup: WARNING: the CLIP graph uses unsupported operators by the backend
warmup:          the performance will be suboptimal
warmup:          list of unsupported ops (backend=Vulkan0):
warmup:          UPSCALE: type = f32, ne = [32 256 1152 1]
warmup: flash attention is enabled
warmup: please report this on github as an issue
warmup: ref: https://github.com/ggml-org/llama.cpp/pull/16837#issuecomment-3461676118
warmup: *****************************************************************
```

so I've added the missing support. The logic is all directly ported from ops.cpp.
