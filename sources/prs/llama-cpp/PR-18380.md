Merry Christmas! I didn't think I'd be working on a PR today but well it just happened.

This basically is an addon to #17813 for the remaining quants, and I made a few optimizations as well. The improvements are small but I feel that they're technically better in the sense that there's no reason to use small loads if we can help it.

We still dequantize two values at a time here so it shouldn't affect coopmat.
