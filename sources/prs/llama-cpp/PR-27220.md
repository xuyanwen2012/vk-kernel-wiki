## Overview

Closes #27194
- Fuses UNARY(GELU|SIGMOID|SILU|SOFTPLUS)+MUL on Vulkan, matching CUDA's unary_mul
- Review-driven additions:
  - GELU support (gemma4/gemma3n per-layer gating)
  - shape check via standard `ggml_can_repeat`
  - fusion of pairs separated by zero-compute nodes (graph_optimize)
  - OP-on-B support (`ffn_shexp * sigmoid(gate)`, qwen3next/qwen35moe shared-expert gating)

## Additional information

### Design:
- Fusion lives in unary.comp behind UNARY_MUL_FUSION. Specialized pipelines per
  op/dtype, repeat + norepeat variants selected by shape equality. Kernel
  scheduled like mul.comp (256 threads x 2 iterations); writes the MUL dst
  directly, never materializing the unary intermediate.
- Shape gating uses the standard `ggml_can_repeat` broadcast check (admits non-1
  repeat factors, matching ggml and CUDA reference semantics).
- Both operand slots supported:
  - unary as src0: other must repeat against it (`ggml_can_repeat(other, unary)`)
  - unary as src1 (OP-on-B, e.g. qwen shared-expert gating `ffn_shexp * sigmoid(gate)`):
