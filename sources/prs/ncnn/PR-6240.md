# Layer norm vulkan shader

Locator: https://github.com/Tencent/ncnn/pull/6240 (pull request description, complete)

<!-- upstream-excerpt-start -->
The Vulkan implementation of layernorm. In order to standardize and make the computation more intuitive, I also modified the format of the cpu-side normlayer. The computation of layernorm uses a partitioned group approach to unify the calculations under different conditions. To avoid being affected by the cstep between channels, the group will only partition within a single channel, without cross-channel grouping.

channel -> group-> h*w
channel -> h -> group -> w
