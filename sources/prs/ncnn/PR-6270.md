# drop vulkan shader pack8

Locator: https://github.com/Tencent/ncnn/pull/6270 (pull request description, complete)

<!-- upstream-excerpt-start -->
The pack8 shader code is designed to round up the fp16 type to 128 bits, thus achieving the correct performance boost for image storage on the old Adreno graphics

As image storage is deprecated, simply pack8 won't provide any performance gains

Let's wait for the vulkan long vector extension


- [x] drop sfpvec8/afpvec8/sintvec8/aintvec8 glsl extension
