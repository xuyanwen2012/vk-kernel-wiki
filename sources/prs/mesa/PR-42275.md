# intel: Change dpas_intel source order to follow DPAS

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/42275 (merge request description, complete)

<!-- upstream-excerpt-start -->
- The general NIR intrinsic (`cmat_muladd`) is `Dst A B C`, which
  follows SPIR-V corresponding operation.
- The DPAS hardware instruction is `Dst = C B A`

Right now the NIR intrinsic for `dpas_intel` has a third order `Dst = C A B`.
Change so it follows DPAS hardware order.
<!-- upstream-excerpt-end -->
