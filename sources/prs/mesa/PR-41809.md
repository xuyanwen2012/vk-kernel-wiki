# nir,radv: add pass to optimize shared variables to subgroup operations

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/41809 (merge request description, first 1200 of 1414 characters)

<!-- upstream-excerpt-start -->
Games commonly use shared memory implement workgroup wide reductions, scans and broadcasts. Sometimes because they use apis without subgroup support, sometimes because subgroup operations are hard to use safely and portable. This new pass can remove all shared variables that are only accessed with constant indexing.

To achieve that, we need to emulate uniform registers and linear control flow on top of NIR which only has a logical control flow graph. In theory, this optimization could be done more efficiently for aco, as there we have a full linear control flow graph without critical edges. But the backend is also too late in the compilation process, this optimization should be done before shared memory is lowered to explicit addresses. And while the optimization is nice to have, it's also not important enough to add similar uniform ssa/linear cfg concepts to NIR.

So uniform emulation it is. For that, I tried to reuse the usual variable to SSA helpers that NIR has, just with an option to insert broadcasts to re-uniformize values when control flow converges.
