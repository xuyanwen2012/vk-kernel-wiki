# radv,nir,aco: optimize cooperative matrix input modifiers and inline constants

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/34396 (merge request description, complete)

<!-- upstream-excerpt-start -->
WMMA instructions support inline constants as the C matrix and floating point neg/abs modifiers. For other alu instructions `aco_optimizer` is responsible for optimizing these, but I think for cooperative matrices it makes more sense to do this in NIR. Handling vectors in aco IR can be quite a nightmare, and WMMA is special enough that the optimization would likely be entirely separate even if we put them in `aco_optimizer`. So we don't lose anything with the NIR approach and hopefully end up with code that's simpler and easier to maintain. Although maybe the inline constant optimization should live in aco isel instead of NIR, because the current solution duplicates the logic for determining if a constant requires a literal.
