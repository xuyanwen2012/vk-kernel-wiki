# ir3, tu: Small subgroup size fixes

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/43010 (merge request description, complete)

<!-- upstream-excerpt-start -->
Turnip and ir3 hardcoded subgroup sizes of 64 or 128 in a few places, which breaks assumptions on devices with a smaller `threadsize_base`, such as A702. These can instead derive or reuse the correct subgroup size.

This fixes most (though not all) subgroup issues on A702.

N.B. There are still a few remaining `THREAD64`/`THREAD128` references that intentionally remain unchanged. These are misleadingly named hardware enums used to select the threadsize mode (single vs double threadsize), not literal subgroup sizes.
<!-- upstream-excerpt-end -->
