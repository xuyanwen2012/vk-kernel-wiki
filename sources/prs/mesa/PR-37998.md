# nak/cmat: vectorize cmat_load and store

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/37998 (merge request description, complete)

<!-- upstream-excerpt-start -->
Initial idea and code from @airlied, but this is a complete rewrite of his
patch.

The Matrix layouts contain groups of values, for int8 we have vec4 groups, for fp16, fp32 and int32 we have vec2s. With this we load and store them as vectors getting rid of a bunch of address calculation.

This also adds support for the MOVM instruction, that can transpose a 8x8 16 bit matrix. We can use this on 16 and 32 bit types to easily transpose matrices while keeping vectorized load/store instructions. For int32 we need to permutate values so they end up in the correct threads. It is unclear if it's in avarage generating better or worse code, but in testing it did seem to not hurt or make things better.
