# panvk: enable Vulkan 1.1 and subgroups on Bifrost

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/41981 (merge request description, first 1180 of 2434 characters)

<!-- upstream-excerpt-start -->
### What does this MR do and why?
<!-- Describe in detail what your merge request does and why. -->

This MR adds missing branch reconvergence on clauses within loops where the successor is outside the loop or immediately after a loop exit. This MR sets reconvergence for all such points, but reconvergence is only required when the iteration count is not warp-invariant. So we could do better by checking for a warp-invariant iteration count. This allows us to support Vulkan 1.1 and subgroups in Bifrost.

Without the changes to branch reconvergence in this MR, the nested loop shown from `dEQP-VK.reconvergence.maximal.compute.nesting3.4.22` has branch reconvergence on blocks B0, B1, B4, B5, B8, B9, B10, B12, and B13 (marked with `*`):

```
       B13*                        B11 -------------
       ^                           ^               |
       |                           |               v
       B3                   B7 --> B9*--> B10*--> B12*
       ^                    ^                      |
       |                    |                      |
B0*--> B1*--> B2 --> B4*--> B5*<---                |
       ^                    |     |                |
       |
