# lvp/radv/nir: add coopmat2 support for Tensor Addressing and Block Loads

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/38589 (merge request description, complete)

<!-- upstream-excerpt-start -->
This adds NV_cooperative_matrix2 support for CooperativeMatrixTensorAddressingNV and CooperativeMatrixBlockLoadsNV to radv and lavapipe

TensorAddressing requires two 2 new vtn types, which are converted to GLSL structs and let struct splitting and dce cleanup the unused bits and hopefully optimize them efficiently.

The load/store operations are added cmat_call operations. Why basic load/store could be intrinsics, once block load decodes are added, a cmat_call is required, so for consistency across load/stores, I used cmat_call operations.
<!-- upstream-excerpt-end -->
