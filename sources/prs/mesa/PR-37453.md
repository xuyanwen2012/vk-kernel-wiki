# amd: allow for unsigned wraps when folding shared memory offsets

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/37453 (merge request description, complete)

<!-- upstream-excerpt-start -->
LDS addressing is entirely done in 32-bit. We already used `nir_opt_offsets` for non-wrapping additions and later optimized (most of) the remaining additions in ACO. Just do the handling in `nir_opt_offsets` instead. If we ensure that the resulting offsets are within bounds (0, UINT16_MAX), overflows don't cause any issues.
<!-- upstream-excerpt-end -->
