Vulkan spec: https://registry.khronos.org/vulkan/specs/latest/man/html/VK_KHR_shader_bfloat16.html

SPIR-V spec: https://github.khronos.org/SPIRV-Registry/extensions/KHR/SPV_KHR_bfloat16.html

_On top of Intel specific commits !33664, !34035 and !34031._

_On top of spec update MRs !34092 (spirv) and !34106 (vulkan)._

_Using !34506+ to land some intel specific patches._

The new extension adds a new type BFloat16 to SPIR-V, allow it to be used in a small set of operations (constants, conversions, dot product) and also as a type for cooperative matrix configurations.

Due to the small set of operations supported, the current MR don't add a new NIR ALU type, instead mapping BFloat16 values into uint16 and using specific operations for those.  This approach was chosen based on conversation with @alyssa in the past.
