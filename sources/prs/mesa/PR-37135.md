# nvk: rework shared memory QMD handling and make compute faster

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/37135 (merge request description, complete)

<!-- upstream-excerpt-start -->
So I've noticed that for certain workloads, setting a higher shared memory target gives me an up to 2x speed up with compute shaders.

Apparently some games (e.g. Atomic heart, makes the game menu not a lagging hell as reported by @phomes ) see performance improvements from this as well.

This MR does the following:
- Per device shared memory limits with their known L1 cache splits (only really matters for Kepler, Volta and newer)
- Refactors the QMD gen code to not hard code hw limits and also accept higher shared memory sizes.
- Sets the shared memory target to the max.

Please test and benchmark. This _should_ help with games doing compute based upscaling or frame generation, so maybe turn those options on/off to see if that makes a difference.
