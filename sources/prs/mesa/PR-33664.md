# brw: Add EU assembler support for BFloat16 including EU validation

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/33664 (merge request description, complete)

<!-- upstream-excerpt-start -->
Registers with BFloat16 are supported since Gfx12.5, so let's start to take advantage of it by adding support for generating this register type. This MR will add the new BRW_TYPE_BF, code generator and assembler support.  It also adds an executor example showing some conversion tricks (needed to side-step restrictions).

Note: using the name BF instead of BF16 here to follow the conventions and the PRMs.
<!-- upstream-excerpt-end -->
