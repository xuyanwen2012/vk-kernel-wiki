# nir: rework subgroup size information

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/37258 (merge request description, complete)

<!-- upstream-excerpt-start -->
We have too many places in NIR where the subgroup size is specified. This takes `enum ENUM_PACKED gl_subgroup_size` and splits it into api and min/max hw subgroup size in the shader info struct.

The long term goal is to use these to replace `nir_lower_subgroups_options::subgroup_size` and `nir_unsigned_upper_bound_config::min_subgroup_size/max_subgroup_size`. Backends can update the info when they make new decisions about the subgroup size. But this MR doesn't do that yet, it just tries to not break all the subtle details everywhere.
<!-- upstream-excerpt-end -->
