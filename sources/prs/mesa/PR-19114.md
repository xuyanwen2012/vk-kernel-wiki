# aco,ac/llvm,radv,radeonsi: Integer dot products on GFX11.

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/19114 (merge request description, complete)

<!-- upstream-excerpt-start -->
`v_dot4_i32_i8` and 16bit idot were removed but `v_dot4_i32_iu8` was added.
`v_dot4_i32_iu8` can use neg_lo to specify signedness for the first two operands: <https://reviews.llvm.org/D127904>, so we can implement both sdot_4x8 and sudot_4x8 with it.
<!-- upstream-excerpt-end -->
