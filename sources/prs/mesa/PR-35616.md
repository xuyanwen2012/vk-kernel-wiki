# anv: Add support for Float16 as cooperative matrix destination/accumulator

Locator: https://gitlab.freedesktop.org/mesa/mesa/-/merge_requests/35616 (merge request description, complete)

<!-- upstream-excerpt-start -->
https://gitlab.freedesktop.org/mesa/mesa/-/issues/13304

This MR adds, implements, and makes use of a new intrinsic `convert_cmat_intel` that allows us to implement type-conversions of cooperative matrices in the backend compiler.

dEQP-VK has tests for converting B-type matrices, but all of them result in "NotSupported" for reasons that are unclear to me. As such, dropping the last commit ("brw: Implement convert_cmat_intel intrinsic for B-type matrices") makes no difference in the dEQP-VK results. Instead, I tested that code using the vkrunner tests I created in https://gitlab.freedesktop.org/mesa/mesa/-/issues/13304#note_2957887. They all pass on RPL and PTL, the two devices I tested on. If we want to land this commit, it probably could use some further cleanups.
